# iOS 子页面 UI 补齐记录

日期：2026-10-25。对应当前源码版本 1.0.6 (7)，不是新包发行公告。

## 已修改

- 买家交易：订单筛选、订单卡片、详情状态、确认订单、售后申请、凭证缩略图、退货物流与星级评价。
- 地址：地址卡片、新增/编辑表单、固定底部保存按钮；移除重复新增入口。
- 商家：入驻与经营资质、店铺资料、库存调整、商家订单列表、发货/数字交付/到店核销/售后回复页面。
- 钱包：钱包绑定、充值、提现、兑换、交易记录、质押方案与记录。
- 个人与设置：资料编辑、账号安全、修改密码、通知设置、权益、版本记录、收藏、经营记录、协议阅读。
- 帮助：客服工单、反馈、提问、邀请与奖励记录。

本次共调整 31 个页面视图和 1 个订单卡片组件。新增共享详情页、标题、分组卡片字段、状态标签、横向筛选、时间线、底部操作区和相册缩略图组件。页面按现有安卓卡片/字段/操作的层级重排，保留 iOS 系统导航和返回。确认订单、售后、资料编辑、密码、地址、入驻及出入金等关键表单提供底部操作区。

## 功能保护

与改动前快照比较，6 个业务源码文件的原有方法实现及字面量 API 调用集合保持一致；支付/提现/兑换/质押的请求编号、结果恢复、报价到期和确认逻辑均保留。通知设置保留权限、开关与应用生命周期事件。没有变更通话、安卓、服务端或签名凭据。

## 检查与限制

- 67 个 Swift 文件解析无语法错误；97 个字面量 API action 与本地后端对照无缺失。
- 已检查改动页面不再使用原生 List/Form 作为整体布局；业务列表仍保留筛选、分页、刷新、错误和空态处理。
- 源码结构检查不等于 Xcode 编译或真机验证。本机是 Windows，尚未执行 iOS 编译、逐页截图比对、键盘与大字体真机检查或支付业务操作。
