# iOS 1.0.4（5）修复说明

日期：2026-10-24。范围为 iOS；Android 客户端未改动。此记录承接第二轮审查及 1.0.3 实现，区分代码完成、自动验证和设备验收。

## 已完成代码

- 聊天列表删除顶部重复通讯录入口；主导航独立页面栈，切换入口回到根页，聊天隐藏底部导航，二级页面保留返回。
- 聊天优先恢复本地消息，后台增量同步；媒体缩略图异步解码、限制视频封面并发；空、错、同步状态可见。
- 图片、视频、语音、文件使用持久发送队列，先显示待发气泡及进度；失败支持重试/删除；附件与来信共用稳定时间轴，服务端精简回执保留媒体内容。
- 可见已读与同步游标分离，看历史消息时不提前清除新来信未读。
- 通话先开麦成功再显示接通和计时，业务状态上报异步重试；权限/SDK失败可见，前台有 CallKit 不可用的回退路径。语音消息播放只释放自身持有的音频会话。
- 红包弹窗中央提供“拆”，领取成功拉取结果、失败可重试；余额计算仍由后端执行。
- 资产列表统一 SPX001 展示，金额展示保留两位，不截断提交/交易计算精度。
- 清缓存时移除旧下载任务，任务身份/账号隔离防旧回调污染；当天媒体也参与容量回收；缩略图、视频分块、发送后缓存写入时继续执行预算回收，保护当前文件/目录。
- 相册保留 GIF/透明 PNG 文件，提供原图选项；聊天缩略图按首帧显示，不承诺列表内自动播放动图。大视频导入做大小及空间预检，减少复制；文件下载有进度/取消/重试。
- 兑换/结算先恢复待核对请求，原子保留避免覆盖旧记录；退出登录先完成本机退出，旧凭据撤销不阻塞。
- 加群搜索与确认结果绑定，旧响应失效，加入时防重复提交；经营概览区分失败与未开店。
- 商品视频保留本地源及上传 ID，继续/放弃入口可用；发布使用稳定请求 ID 和结果核对。本轮增加批量图片逐项重试/移除，清空相册选择不丢失败队列，容量溢出项和其他批次失败项保留。
- 配套后端增加商品发布幂等结果与取消标记、稳定嵌套字段顺序、409/422 映射。没有 request ID 的旧 Android 契约保留。

## 验证与部署

- 本地 Swift 语法/接口名称扫描通过；这不等同于 Xcode 类型检查。
- 三个本地 PHP 文件语法检查通过。
- 商品恢复隔离回归测试通过 14 项断言，不连接生产数据库；覆盖原请求重试、响应丢失核对、取消后晚到原请求、字段次序稳定、跨账号隔离。测试不证明 MySQL 并发锁。
- 已修正旧云端运行 40070749659 中测试 Record 与 Combine.Record 的歧义；本版本需要以 GitHub Actions 对应提交的编译、XCTest、未签名归档结果为准。
- 后端补丁在 server-companion/。当前服务器连接不可用，尚未确认本轮部署。新版在服务未支持 product_request_recovery 时暂停商品提交并保留草稿，避免不安全重试。
- 当前没有产出新的已签名 IPA；完成编译验证后，使用现有加密签名工作流打包。
