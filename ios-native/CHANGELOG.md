# iOS 版本变更

## 1.0.21 (22) · 2026-11-04

- 钱包新增 FISS 资产展示、估值、充值/提现与质押支持；质押方案和数量校验按资产规则处理。
- 完善登录/注册流程、媒体上传与播放、二维码扫描兼容，以及聊天和红包交互。
- 红包发送与领取支持 SPX001/FISS，显示对应币种并使用独立支付密码。
- 本地源码与资源已同步；仍需在 macOS 执行 Xcode 编译及真机验收后再作为正式发行版本。

## 1.0.17 (18) · 2026-11-01

- 新增 FISS 代币：钱包展示余额与 AVE 估值、充值/提现支持 FISS、质押页支持 SPX001/FISS 切换。
- 质押方案按币种隔离：步长、最低额、单人上限全部由服务端方案字段驱动（FISS 步长 1、无上限）。
- 修复：质押数量校验曾写死 100000 整数倍，导致 FISS 无法提交。
- 质押确认弹窗展示周期、年化、到期日与实时预计收益。
- 仍未执行 Xcode 编译与真机验收；本次代码记录不是发行公告。
