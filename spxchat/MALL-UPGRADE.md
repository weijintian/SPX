# SPX 商城 1.46 更新说明

生成日期：2026-10-13。Android 正式版 1.46（versionCode 47），包名 com.spx.chat，沿用原发布证书。按照用户要求，服务端更新，APK 仅上传至服务器私有目录备用，暂不登记发布、不替换公开下载文件。

## 本次修复

- 店铺头像从手机选择图片、压缩上传，支持预览、更换和删除。
- 经营资质支持最多六张手机图片，支持预览和删除；后台审核页查看缩略图和原图。
- 移除可见经纬度和坐标系输入，通过“从地图选择店铺位置”返回内部定位数据；详细地址仍可补充。
- 提交开店申请后由后台审核；审核通过才能缴纳保证金。初级十万、黄金一百万 SPX001，沿用原规则。已审核资质不能由商家自行替换。
- 商城两分钟缓存先显示后刷新，十五秒内避免重复请求；相同结果不重复重绘。聊天等无关请求不再清空商城缓存，账号和服务器切换时清空。
- 数据库初始化通过代码指纹及互斥锁避免每次请求重复执行建表、改表；商品图片批量查询，公开商城读取不再触发质押结算，钱包等原结算入口保留。

## 资质隐私与存储

资质文件默认位于 Web 根目录外的 /var/www/.spx-mall-private/qualifications，可通过服务器 mall.private_media_dir 配置。目录权限 700，文件权限 600，PHP 运行用户须拥有读写权限。资质仅申请人本人以及有权限且关联该商户的后台管理员可读取，不出现在公开店铺响应中。

上传校验真实 MIME、大小和像素上限，引用的资质必须归申请人所有。头像为店铺公开图片，保存于 uploads/mall。服务端升级不得覆盖原配置、密钥、上传内容。备份须包含新增的私有资质目录。

## 服务端更新

SPX-MALL-1.46-server-update.zip 为现有服务端覆盖更新包，包含十一份代码及说明和 release-manifest.json；不含配置、账号密码、上传资料或签名私钥。

1. 备份完整站点、数据库和发布记录，先在独立数据库恢复备份并演练迁移。
2. 保留服务器配置，将压缩包的 spxchat/ 对应到站点根目录。确保同时更新 index.php、db.php、schema.sql、mall.php、mall_schema.php、mall_schema.sql、mall_commerce.php、mall_merchant_media.php、spxchat-systemadmin/admin.php、spxchat-systemadmin/mall_admin.php 和本说明。
3. 在短暂维护窗口切换文件并初始化数据库，核验 mall_schema_versions 包含 1、2、3，以及 merchants.qualification_images 已建立。app_settings.runtime_schema_fingerprint 为初始化版本标记。schema.sql 不能作为现有数据库整库重建脚本执行。
4. 配置公开图片目录与私有资质目录权限，刷新 PHP 缓存，核验 HTTP、HTTPS、后台入口、文件哈希和既有业务数据。
5. 本次不发布 APK。新表单和客户端缓存需安装 1.46 才能看到；公开发布版本继续保留，后续修改完成后再统一发布。

## 保留的商城规则

商家商品通过服务器资料和业务规则校验后自动上架；开店申请仍为人工审核。商品自动审核不包括 AI 图像识别。初级升级黄金补九十万 SPX001，保证金独立冻结；关店七天且订单、售后、货款处理完毕后财务审核退回。

下单使用十分钟有效的服务器报价，资料、价格或地址变化需重新确认；同一报价和请求防重复扣款。商品销售收入待结算，完成七天后且没有售后由财务审核结算。现有商品、规格、订单、退款、退货、到店核销与后台规则沿用 1.45。

迁移为新增结构，切换核对原有表、原字段记录未变化。异常时优先恢复旧代码；已经发生真实业务后不得直接覆盖旧数据库备份。
