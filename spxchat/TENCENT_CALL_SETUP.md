# 腾讯云通话服务配置

一对一语音和视频使用 Tencent RTC Android `TUICallEngine`；业务账号、好友校验、在线状态和通话记录由 SPX 服务端管理。可以向离线好友发起呼叫，呼叫页面会持续等待，约 65 秒无人接听后结束。接收方在等待期间打开 App 并完成通话服务连接后，主叫会自动尝试连接。当前不提供离线推送来电或后台唤醒。

离线等待每约 2 秒查询接收方是否就绪；SDK 邀请遇到离线回调后至少间隔 8 秒再尝试。每次重试只使用原呼叫剩余时间，不延长超时。接收设备在收到邀请并通过身份、在线设备校验后绑定，同一个会话不允许其他设备接管。取消、忙线、拒绝和超时仍通过服务端生成一次通话记录。

普通操作提示通过 `AppNotice` 在屏幕中央显示 2 秒，新提示替换旧提示，页面停止时关闭；需要用户操作的权限和确认对话框保持原有交互。

## 服务端密钥

将本地 `android-native/keys/tencent-call.env` 的两项配置安全地写入服务器 `/etc/spxchat/tencent-call.env`，文件仅允许 PHP 服务账号读取，建议权限 `0640`、归属 PHP 服务组。不要把该文件放进网站目录或 APK。

```dotenv
TENCENT_CALL_SDK_APP_ID=你的腾讯云音视频应用SDKAppID
TENCENT_CALL_SDK_SECRET_KEY=腾讯云音视频应用密钥
```

PHP 可直接读取默认路径，也可由 PHP-FPM/Apache 服务环境变量 `SPX_TENCENT_CALL_ENV_FILE` 指定其他绝对路径。PHP 运行环境需启用 PDO MySQL；首次使用通话接口会安装通话状态和在线设备表。

## 发布

把本次 `spxchat` 后端文件部署到服务器后，重载 PHP 服务并从两个已登录账号验证拨打、接听、拒绝、挂断及通话记录。客户端使用 Release 构建；腾讯云密钥不参与客户端构建。

若服务端未配置有效 SDKAppID 和密钥，`calls.credentials` 会返回服务未配置错误，客户端不会开放呼叫。

## 1.63 通话交互与恢复

私聊中服务端生成的语音和视频通话记录可点击重新发起同类型呼叫；群聊和普通用户文本不触发重拨。已有通话时点击记录恢复原通话，不创建第二路。

全屏通话左上角缩小按钮和返回键均进入 App 内通话小窗，可拖动、贴边、点击恢复和挂断。小窗保留原会话、视频视图和计时，键盘出现时限制在可见范围。结束、拒绝、取消和页面销毁清理媒体及小窗。目前不提供系统悬浮窗或后台通话。

SDK 凭证在前台空闲时按单调时钟定期更新；检测到过期或未初始化错误时，拨号阶段最多重新初始化一次，并使用原呼叫剩余时间。重新初始化完成并确认本设备在线后继续拨号。主叫媒体在 SDK 邀请成功或通话接通后开启；缩小与恢复操作也遵守该条件。挂断清理期间阻止重复拨号。

诊断日志仅记录操作、错误分类、错误码和状态，不记录 UserSig、密钥或接口令牌。错误 -1 是通用失败，需结合具体 SDK 操作和双机实测定位；已观察到的 key is expired 已补充恢复处理，不能据此判定所有 -1 均已解决。

验证采用隔离会话，不拨打真实用户；双机接通、真实音视频、弱网重连及远端挂断仍需端到端实测。
